# Code of Conduct

Liberarr follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and welcoming, give and accept constructive feedback, and focus on what is best for the project. Harassment, insults, personal or political attacks, and publishing others' private information are not accepted, in issues, pull requests, discussions or any other project space.

## Reporting

Report unacceptable behaviour to the maintainer, [hocinehacherouf](https://github.com/hocinehacherouf), through GitHub (use "Report content" on the comment, or contact them through their GitHub profile). Reports are handled confidentially. The maintainer may edit or remove contributions and block contributors who break this code, following the Contributor Covenant enforcement guidelines.
